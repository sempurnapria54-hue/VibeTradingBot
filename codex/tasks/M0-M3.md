Задача: Реализовать этапы M0–M3.
Спецификация: см. README.md, ./docs/TECH_STYLE_GUIDE.md, ./docs/stages/M0_BOOTSTRAP.md, M1_MODELS_AND_MAPPERS.md, M2_SCHEMA_AND_MIGRATIONS.md , M3_EXCHANGE_INTEGRATION.md,
а также диаграммы в ./docs/diagrams/**.

Инварианты:
- Java 25, Spring Boot 3.x, jOOQ-only (без Spring Data JPA), Lombok, MapStruct,
  springdoc-openapi-starter-webmvc-ui, Spring Security (JWT; dev можно упростить).
- application.yaml (dev/prod), docker-compose.yaml (PostgreSQL). Без триггеров в БД.
- Все версии зависимостей вынести в <properties> (pom.xml).
- Слои моделей: client/domain/api/persistence. Маппинг только через domain (rich-модель с методами).
- Канонические таймфреймы в YAML + маппинги по биржам; без статуса свечей; coverage_end_utc — учесть.
- Стиль: переменные — по одной на строке; всегда {} после if.

Критерии готовности:
- `mvn -Pdev -DskipTests package` успешен.
- Поднимается PostgreSQL из docker-compose; миграции применяются; jOOQ codegen проходит.
- Swagger UI доступен; базовые контроллеры/каркасы сервисов/коннектора созданы.
Output: PR в ветку feature/M0-M3.
